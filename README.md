# Hotel Project

Система управления гостиничным фондом (учебный проект).

**Вариант:** 5 — Гостиница

## Стек

- Python 3.10+
- Flask 3.x
- SQLite

## Установка

    python -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt

## Запуск

    python app.py

## Тесты

    pytest
